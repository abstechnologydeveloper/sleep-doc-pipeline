# Ambient pipeline boundary

This package is reserved for the upcoming non-narrated ambient workflow.

Planned responsibilities:

- image-to-video API integration;
- instrumental music generation;
- environmental sound mixing;
- seamless visual and audio looping;
- ambient-specific thumbnails and metadata.

Do not move storytelling code here. The existing `src/pipeline/` package remains
the narrated storytelling implementation until an intentional migration is
planned and tested.
